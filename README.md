# DakshVerse

A personal encyclopedia about the things I’m curious about: books, films, history, world affairs, and science.

This is my first website project as a first-year CSE student. I built it with HTML, CSS, and JavaScript while learning, with AI assistance along the way.
I believe in understanding a problem first, then learning the tools and solutions needed to solve it. 
DakshVerse is my first interactive self-learning project and part of my portfolio.

## What’s on the site

- Topics and notes about my interests
- Books and films I recommend
- An interactive world map
- Journal posts and star reviews

Journal posts and reviews are saved in the visitor’s browser; they aren’t shared with other visitors.
